# Efficient Frontier Rebalancing Optimiziation (EFRO)
This project is about finding the optimal frequency 
for rebalancing a market-wide portfolio.

## Overview
The code it self pulles historical data from yahoo-finance.
Using this data it calculates daly returns of each stock in
the selected market, a covariance matrix between the stocks,
....
and creates an Efficient Frontier curve 
from it.
